## 5. 정상 흐름
- 네이티브 계층은 Command/Status/Data 해석, BC/RT/BM 메시지 흐름, Bus A/B 전환, timeout 후 retry, JSONL 저장을 검증한다.
- Host / Interop 계층은 세션 제어, DTO 전달, report export, explicit runtime loader 경계, CLI baseline, one-shot packaging output, 초기 native `MessageFrame` telemetry 전달을 검증한다.

## 6. 비정상 흐름
- 잘못된 시나리오 JSON
- 세션 없는 조회 또는 Bus 전환
- 지원하지 않는 Mode Code
- `BufferTooSmall`
- runtime DLL 누락 / 잘못된 바이너리 / 엔트리 포인트 누락

## 7. 타임아웃 / 재시도
- 네이티브 BC 테스트에서 timeout 이후 단일 retry와 degraded 상태 전환, 연속 timeout 2회 또는 line fault 1회 후 자동 failover를 확인한다.
- Host / Interop는 `BufferTooSmall` 재시도만 담당하고, 프로토콜 수준 timeout / retry는 네이티브 결과를 그대로 전달한다.

## 8. Bus A/B 전환
- 네이티브에서 수동 전환과 자동 failover 모두 active bus 갱신과 BM event를 확인한다.
- Host smoke test에서 `SwitchBusAsync` 호출과 health / telemetry 결과를 함께 확인한다.

## 9. BC -> RT / RT -> BC / RT <-> RT / Mode Code
- 실제 메시지 처리 규칙은 네이티브 테스트에서 검증하고, 대표 Mode Code 5종과 1차 Mode Code 4종, RT ↔ RT 사전 검증 실패를 포함한다.
- Host / Interop 테스트는 위 결과를 다시 해석하지 않고 DTO 전달, 로더 경계, packaging output을 검증한다.
