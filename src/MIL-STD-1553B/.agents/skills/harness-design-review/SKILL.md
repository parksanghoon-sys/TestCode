# MIL-STD-1553B 하네스 설계 검토 스킬

## 목적

이 스킬은 MIL-STD-1553B 하네스 엔지니어링 작업에서 **구현 전에 반드시 수행해야 하는 설계 검토 단계**를 담당한다.

이 스킬을 사용하면 다음을 먼저 정리한다.

- 요구사항과 가정
- 기능 범위와 제외 범위
- C++ / C# 책임 분리
- 클린 아키텍처 레이어 영향도
- 객체 모델 초안
- 인터페이스 초안
- TDD 테스트 전략
- 리스크와 완료 기준

---

## 반드시 지킬 규칙

- 이 스킬 단계에서는 **프로덕션 코드 작성 금지**
- 설계 검토 문서를 먼저 작성하거나 갱신한다.
- 구현 방향을 **C++ / C# / 공통 도메인**으로 분리한다.
- 반드시 **클린 아키텍처** 기준으로 영향 계층을 식별한다.
- 반드시 **OOP 관점의 책임 분리**를 문서화한다.
- 이후 구현 단계에서 사용할 **TDD Red 테스트 계획**을 문서에 포함한다.
- 문서는 반드시 **한글**로 작성한다.

---

## 수행 절차

1. 작업 배경과 목표를 요약한다.
2. 입력, 출력, 장치/프로토콜 제약, 타이밍 요구사항을 정리한다.
3. 이번 작업이 BC / RT / BM 중 어디에 영향을 주는지 식별한다.
4. Bus A/B 전환, 오류 주입, Mode Code, 타임아웃 여부를 검토한다.
5. C++ 과 C# 의 책임 경계를 정리한다.
6. Domain / Application / Infrastructure / Presentation 중 변경 계층을 식별한다.
7. 필요한 클래스, 인터페이스, DTO, 값 객체 후보를 정리한다.
8. 테스트 전략을 먼저 정의한다.
9. 설계 검토 문서를 `docs/design/` 아래에 작성한다.

- 제외 범위
- 요구사항

- C++ / C# 책임 분리

- 리스크 및 대응
- 완료 기준
