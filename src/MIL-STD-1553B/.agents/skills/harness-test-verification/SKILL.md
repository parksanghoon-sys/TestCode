# MIL-STD-1553B 하네스 테스트 및 검증 스킬

## 목적

이 스킬은 구현이 완료된 기능을 검증하고, 테스트 코드와 테스트 문서를 마무리한다.  
단순히 테스트 실행만 하지 말고, **TDD의 Red/Green/Refactor 흔적이 남도록** 결과를 정리한다.

---

## 반드시 지킬 규칙

- 구현만 완료했다고 끝내지 않는다.
- 테스트 코드와 테스트 문서를 함께 갱신한다.
- 정상 흐름과 비정상 흐름을 함께 다룬다.
- MIL-STD-1553B 특성상 **버스 전환, 타임아웃, Mode Code, 오류 주입**을 빠뜨리지 않는다.
- 결과 문서는 반드시 한글로 작성한다.

---

## 필수 검증 항목

- BC → RT 메시지 흐름
- RT → BC 메시지 흐름
- RT ↔ RT 중계 흐름
- Command Word 해석
- Status Word 해석
- Data Word 수 / 길이
- Subaddress 처리
- Mode Code 처리
- 타임아웃
- 재시도
- Bus A/B 전환
- 오류 주입 및 복구
- 로그 / 트레이스 검증

---

## 테스트 절차

1. 설계 검토 문서의 테스트 전략을 다시 읽는다.
2. 구현된 코드와 테스트 범위를 대조한다.
3. 누락된 단위 테스트와 통합 테스트를 추가한다.
4. 실패 재현 테스트가 실제로 실패하는지 확인한다.
5. 수정 후 테스트가 통과하는지 확인한다.
6. 리팩터링 후 회귀 테스트를 다시 확인한다.
7. `docs/test/` 아래 결과 문서를 작성하거나 갱신한다.
