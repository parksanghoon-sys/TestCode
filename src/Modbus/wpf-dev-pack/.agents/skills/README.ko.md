# WPF Dev Pack 스킬 인덱스

이 디렉터리에는 WPF 및 .NET 작업용 Codex 스킬이 들어 있습니다.

## 스킬 이름을 실제 파일로 찾는 방법

- 규칙 문서에서 `optimizing-memory-allocation`처럼 스킬 이름만 언급할 수 있습니다.
- 이런 경우 실제 경로는 `wpf-dev-pack/.agents/skills/<skill-name>/SKILL.md` 입니다.
- 일부 스킬에는 `QUICKREF.md`, 템플릿, 예제가 함께 있습니다.
