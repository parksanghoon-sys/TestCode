# WPF Dev Pack skill index

This directory contains Codex skills for WPF and .NET work.

## How to resolve skill references

- A rule may mention a skill by name like `optimizing-memory-allocation`.
- Resolve that name to `wpf-dev-pack/.agents/skills/<skill-name>/SKILL.md`.
- Some skills also include `QUICKREF.md`, templates, or examples.
