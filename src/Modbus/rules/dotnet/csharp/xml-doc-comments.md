# C# XML 주석 규칙

## 목적

새로 작성하거나 수정하는 C# 코드에서 클래스와 함수의 역할을 빠르게 이해할 수 있도록, XML 형식의 한글 주석을 기본 규칙으로 유지한다.

## 기본 규칙

- 새로 작성하거나 수정하는 `class`, `record`, `struct`, `interface`, `enum`, `method`, `constructor`에는 반드시 XML 형식의 한글 주석을 작성한다.
- 최소한 `<summary>`는 항상 작성한다.
- 매개변수가 있으면 `<param>`을 추가한다.
- 반환값이 있으면 `<returns>`를 추가한다.
- 호출자가 알아야 할 예외 조건이 분명하면 `<exception>`을 추가한다.
- 테스트 클래스와 테스트 메서드도 예외 없이 같은 규칙을 적용한다.

## 작성 원칙

- 구현을 그대로 번역하지 말고 역할, 의도, 도메인 의미를 설명한다.
- 한글 문장은 짧고 명확하게 작성한다.
- 주석과 실제 코드 동작이 어긋나면 코드를 기준으로 즉시 함께 수정한다.
- 주석 누락이 보이면 해당 변경 범위 안에서 같이 보완한다.
